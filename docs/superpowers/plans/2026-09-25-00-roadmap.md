# WhatsApp Sticker Maker — Plan Roadmap

**Spec:** `docs/superpowers/specs/2026-09-25-whatsapp-sticker-maker-design.md`

The spec covers five subsystems. Each gets its own plan, and each plan ends with software that runs on a device and can be tested on its own. Plans 3–5 are written after the plans they depend on have been executed, so they target the real code. Plan 2 only depends on the spec's §7 interface and lives in its own folder (`modules/webp-encoder/`), so it can be written and executed in parallel with Plan 1 once Plan 1's Task 1 (scaffold + Android build) is done.

| # | Plan | Delivers | Spec sections | Depends on |
|---|------|----------|---------------|------------|
| 1 | Foundation + WhatsApp integration | Scaffolded Expo app, domain types, validation, pack storage, packs/settings stores, bundled static starter pack, Home and Pack screens (details, reorder, delete, emoji edit, duplicate), `sticker-provider` module, Add to WhatsApp + status badge | §3, §4, §5, §6, §8 (Home, Pack), §10, §12 (INTERNET only), §13 (WhatsApp, storage), §16 | — |
| 2 | `webp-encoder` native module | libwebp via CMake; `encodeStatic`, `makeTrayIcon`, `inspect`, `probe`, `encodeAnimated` with frame cache, transforms and smooth/sharp size fitting | §7, §15 (Kotlin + instrumented) | 1 |
| 3 | Static sticker creation | Media screen Device tab (permissions, filters, multi-select) + system picker fallback, static editor (Skia canvas, Fit/Fill, crop tool, text/emoji layers, undo/redo, re-edit), batch queue, tray icon picker | §8 (Media Device tab, Framing rule, Static editor), §12 | 1, 2 |
| 4 | Animated stickers + GIF search | Animated editor (framing, trim, speed, playback, rotate/flip, fps, priority, effective duration), Klipy + Giphy providers, GIF Search tab | §8 (GIF Search, Animated editor), §11 | 1, 2 |
| 5 | Import/Export, Settings, release | `.wastickers`/zip export (share + save to folder), importer (keep/fix/skip, split, id collision), Settings screen, reduce motion, release APK script, README completion, manual QA checklist | §9, §8 (Settings), §14, §15 (manual QA), §16 | 1–4 |

**Update 2026-09-28:** bundled starter packs were removed from the app (spec §5.3). Plan 1's static starter pack, its read-only mode and "Duplicate to edit" are gone, and Plan 2 no longer ships an animated starter pack.
