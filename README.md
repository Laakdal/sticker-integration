# Sticker Maker

Personal Android app for creating and managing WhatsApp sticker packs. Built with Expo SDK 57 (React Native, TypeScript) and two local native modules.

## Requirements

- Windows with Git Bash, Node 22+
- JDK 17 (`winget install --id Microsoft.OpenJDK.17 -e`)
- Android SDK at `%LOCALAPPDATA%\Android\Sdk` with platform 36, NDK 27 and CMake 3.22
- An Android 9+ phone with USB debugging, or an emulator

## Setup

```bash
source scripts/env.sh          # sets JAVA_HOME (JDK 17) and ANDROID_HOME for this shell
cp .env.example .env           # add EXPO_PUBLIC_KLIPY_API_KEY / EXPO_PUBLIC_GIPHY_API_KEY
npm install
npx expo run:android           # builds, installs and starts the app on a connected device
```

`npm install` and `npm ci` rely on the committed `.npmrc` (`legacy-peer-deps=true`) to resolve peer dependency conflicts with Expo.

`android/` is generated by `npx expo prebuild` and is not committed. Change native configuration in `app.config.ts` or `modules/`, then run `npx expo prebuild --platform android --clean`.

## Tests

```bash
npm test                                                     # typecheck + lint + Jest
source scripts/env.sh && npx expo prebuild --platform android --clean && (cd android && ./gradlew :sticker-provider:testDebugUnitTest)   # Kotlin unit tests
```

## Regenerating the starter pack

`npm run generate:bundled` re-renders `assets/bundled-packs/`. Bump `BUNDLED_PACKS_VERSION` (the generator writes it) when the contents change so installed apps re-copy the pack.
